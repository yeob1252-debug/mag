이럴땐 AI | 서비스별 문의 설계

공통 필수: 이름 또는 닉네임 / 답변 이메일 / 원하는 결과 / 수집 동의.
콘텐츠 제작: 상품·메뉴 / 영상 길이 / 사용할 채널.
홈페이지: 브랜드 / 필요한 페이지 / 자료·문의 기능.
원데이클래스: 희망 지역 / 인원 / 만들고 싶은 결과.
맞춤 문의: 현재 업무 / 바꾸고 싶은 부분.
선택: 희망 일정 / 참고 링크.

저장할 관리 항목: 접수번호 / 시각 / 서비스 / 고객 답변 / 동의문 버전 / 유입 콘텐츠 / 처리 상태 / 알림 발송 상태.
흐름: 입력 검증 → 서버 접수 → 시트 저장 → 저장 확인 → 담당자 알림 → 방문자 완료 안내.
중복 방지: 같은 접수번호로 재시도했을 때 행과 메일을 다시 만들지 않는지 확인.
오류 안내: 저장을 확인하지 못하면 완료라고 표시하지 않고 입력을 유지.
테스트: 서비스마다 TEST 표시로 한 번 접수 → 시트의 실제 값 대조 → 알림 발송 로그 → 담당자 받은편지함.
